PROJECT PLANNING INFORMATION
The project name is - Caffeine Tracker
This project aims to create a website that allows users to track their drinks consumed throughout the day, and track their total caffeine consumed for that day.
This project is aimed at all consumers of caffeine that are curious about how much caffeine they are actually drinking, and whether or not they might be drinking too much caffeine per day. This website helps users to better understand their caffeine drinking habits, and helps them to realise when they might be drinking too much. This will help users to avoid over-consuming caffeine.

USER STORIES
As a user I want to see a simple list of everything I've drunk today, so that I can double-check my history.

As a busy user, I want to log a drink just with one or two taps, so that I don't get annoyed by the process and stop using the app.

As a coffee enthusiast, I want a database of popular drinks (Starbucks, Costa, Red bull), so that I don't have to manually look up caffeine content every time.

As a user I want to be able to edit caffeine content of a drink manually so that I can account for a "double shot" or a weaker tea

As a user I want the app to support dark mode, so that it doesn't hurt my eyes when I log a late-night decaf.

As a user, I want to delete a drink log if I clicked it by accident, so that my daily total isn't wrong.
